### Qual é o objetivo do projeto Digital Store?
- Criar uma página de e-commerce para uma loja de varejo.

### Quais são as três páginas obrigatórias da aplicação?
 - As principais páginas:
    HomePage: página inicial, com banners, coleções e produtos em destaque.
    ProductListingPage: página de listagem de produtos, com opções de filtro e ordenação.
    ProductViewPage: página com informações detalhadas de um produto.

### Quais tecnologias você pretende utilizar e para que serve cada uma?
- Devemos utilizar JavaScript com React para escrevermos os componentes JSX para a criação da estrutura da nossa página que serão atualizados dinamicamente.
- CSS para estilização das páginas.

### Quais são as cinco primeiras tarefas que precisam ser realizadas para começar o desenvolvimento?
1. Criação do repósitorio no GitHub e preparação da máquina.
2. Instalação das ferramentas e depedências.
3. Crição das páginas HomePage, ProductListingPage e ProductViewPage e estilização da página.
4. Criação dos componentes Header, Section e Footer.
5. Revisão da aplicação anterior ao deploy.
